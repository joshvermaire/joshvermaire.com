# Repository instructions

## Copy style

- Write user-facing site copy in natural sentence case.
- Preserve official capitalization for proper names, product names, acronyms, and technologies, including Josh Vermaire, AI, SaaS, SDK, TypeScript, React, Next.js, React Native, GitHub, and X.
- Do not use the U+2014 em dash in user-facing copy, metadata, comments, or documentation. Rewrite the sentence with a period, comma, colon, parentheses, or a middle dot instead.
- Before finishing copy work, search the repository for U+2014 and rewrite every occurrence.
